private by design. event text never leaves your browser.

runtime flags

recommended: gcal.notify = "Desktop notifications"

In Calendar settings → Notification settings, set Notifications to:

Desktop
Recommended. Every reminder Calendar shows is caught.
Alerts
Works only when Calendar's wording is recognized (e.g. "starts in").
Off
Nothing is shown in the browser, so there's nothing to detect.

how it works

Calendar Alarm amplifies reminders Google Calendar already shows. It never touches your Google account, the Calendar API, or any server. Allow notifications for calendar.google.com and make sure each calendar or event has a notification configured.

privacy policy · no creds. no servers. no tracking.
